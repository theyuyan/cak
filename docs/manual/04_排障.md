# 排障

先记住一条：**账本是事实源**。任何"它到底干了什么"的问题，答案都在 `~/.cak/sessions/<session>.sqlite`。

```bash
S=~/.cak/sessions/<session>.sqlite
sqlite3 $S "select seq,type,substr(body,1,160) from events order by seq desc limit 40"       # 最近发生了什么
sqlite3 $S "select body from events where type in ('invocation.denied','invocation.failed')"  # 谁被拒/谁失败、为什么
sqlite3 $S "select count(*) from events where type='invocation.requested' and body like '%\"name\":\"model.generate\"%'"  # 模型调了几次
```

## 现象 → 原因 → 处理

| 现象 | 多半是 | 处理 |
|---|---|---|
| `deepseek 401` / `anthropic 401` | key 不对或没放对位置 | `~/.cak/secrets/deepseek.key`（0600，文件里只有 key）；Anthropic 看 `ANTHROPIC_API_KEY` |
| 启动时 `✗ MCP xxx 启动失败：timeout` | `npx -y` 首次下载慢，30s 内没握上手 | 先手动跑一次那条 `npx -y …` 让它下完；再启动 |
| `registry clone failed` | 拿不到 `theyuyan/cak-registry`（私有仓库权限 / 断网） | 有权限：`gh auth login`；断网：`--registry <本地目录>` 或 `--no-registry` |
| `✗ 未安装 xxx：本机一致性测试 N 项未过` | 插件在你机器上没过 conformance | 看列出的失败项：`C1.declares` = 契约 digest 不匹配（插件老了）；`C5.idempotent` = 输出含变化字段；`C2.sampleArgs.valid` = 注册表样例参数不合契约 |
| `ARGS_INVALID: … must have required property` | 模型给的参数不合契约 | 正常防线，模型会重试；反复出现说明契约描述不清，提 issue |
| `CAVEAT_VIOLATION` | 句柄不允许（路径越界、参数超限、target 不对） | 也是正常防线；要放开就在审批时 `s`，或改 spec |
| `APPROVAL_INVALID: 审批被拒绝` | 你按了 N，或 `--task` 没带 `--yes` | 预期行为 |
| 模型一直重复调同一个工具 | 结果没回喂到（多为大结果或线程配对问题） | 已知修过两回；查账本里该调用的 `invocation.executed` 有没有 `output`/`outputPreview`；仍复现请带账本提 issue |
| 一次任务花了 10 万+ token | 长线程整份重发 | 已知限制；拆小任务、别让它整篇读大文件（它有按行读） |
| `sql.query` 报 `unknown db alias` | 没配连接或别名拼错 | `~/.cak/sql-query.json` 里的 key 就是别名 |
| `sql.query` 报 `rejected: …` | 语句不是单条只读 SELECT | 预期：它只做只读 |
| 审查回执 `✗ 回执验证失败` | 审查方换过身份钥匙 / 事件被改 | 重启 cak-code 重新取名片；仍失败视为对方账本不可信 |
| 重启后旧任务里的大结果不见了 | >16KB 结果的 blob 只在内存 | 已知限制（待做 SQLite blob） |
| Node 报 `node:sqlite` 不存在 | Node < 22 | 升级 Node |
| Windows 上各种路径问题 | 没在 Windows 测过 | 先别用 Windows；欢迎报 issue |

## 什么都不对时

```bash
cd ~/agent-kernel && npm test         # 内核自身
node tools/api-surface.mjs            # 接口面有没有被本地改动
npx tsx bin/cak.ts conformance --subprocess "node ~/.cak/plugins/<id>/src/plugins/<id>/dist/main.js" --contract <name> --args '{…}'   # 单测某个已装插件
```
提 issue 请附：命令、完整输出、`npm test` 结果、相关会话账本（先确认里面没有你不想给的内容——账本记了工具结果）。
