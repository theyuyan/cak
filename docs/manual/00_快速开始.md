# 快速开始（5 分钟跑通 cak-code）

> 这份手册面向**用**它的人，不是设计者。设计文档在 `docs/design/`。
> 现状（2026-08-19）：仓库公开、npm 已发（`@cak-dev/cli` / `@cak-dev/sdk` / `@cak-dev/create-plugin`）；版本号以 `cak --version` 为准（CHANGELOG 有每版差异）。

## 你需要什么

| 依赖 | 版本 | 为什么 |
|---|---|---|
| Node.js | **≥ 22**（本机 25 已验） | 账本用内置 `node:sqlite`，Ed25519 用内置 crypto |
| git | 任意 | 拉代码、`cak add` 从 git 源装插件 |
| 一个模型 API key | DeepSeek（已验）或 Anthropic（后端有、未联网验过） | cak-code 要调模型 |
| python3 ≥ 3.9 | 可选 | 只有装 Python 写的插件才要 |

Windows：**没测过**。代码里已按 Windows 惯例处理了 `os.homedir()`、`npm/npx/tsx` 的 `.cmd` 垫片，但没有一台 Windows 机器跑过——第一个在 Windows 上试的人请提 issue。macOS（Intel）已验，Linux 路径写法一致。

## 1. 装 `cak` 命令

只用（推荐）：
```bash
npm i -g @cak-dev/cli      # 之后 cak --version 应打印 cak 0.3.x（npm 装时若看到 esbuild allow-scripts 的 warning，可忽略：不影响运行）
```

要改内核代码 / 跑测试（开发者路径）：
```bash
git clone https://github.com/theyuyan/cak.git ~/agent-kernel
cd ~/agent-kernel
npm install
npm test          # 期望：全绿（1 个联网测试默认跳过）；不绿就别往下走——把输出贴给维护者
npm link          # 让 `cak` 指向这份源码（覆盖上面 npm i -g 的那份）
```

环境体检（只读，不改任何东西、不显示密钥）：
```bash
cak doctor
```

## 2. 用：一个词

```bash
cd 你的项目
cak
```
第一次会问你要模型 key（隐藏输入，直接写进 `~/.cak/secrets/deepseek.key`，不经任何对话/日志）。然后它自己：在这个目录起内核（git 仓库默认编程助手，否则空内核）→ 打开界面。下次同目录再敲 `cak` 就是同一个会话，内核已在跑就直接复用。

- 换界面：`cak --front web`（浏览器）/ `--front tty`；`cak front --default web` 记住
- 换 agent：`cak --agent bare`（空内核）/ 自定义名；`~/.cak/config.json` 里 `agent` 记默认
- 停：`cak stop`（不停也没事：不调模型不花钱，只听本机）
- 想让它多会什么：直接说"我想让你能…"

想分开控制（多个界面看同一会话、脚本用）再用 `cak up` / `cak front` / `--session`。
